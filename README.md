## About

TaskPetal is a lightweight, browser-based task tracker designed to help you organize everyday responsibilities in a calm, welcoming space. Its dark plum interface, soft pastel accents, and sakura-inspired details make managing tasks feel less like another chore.

No accounts, backend, or database are required. Your tasks are saved locally in your browser.

## Features

- **Task management** — Add, edit, complete, and delete tasks.
- **Custom categories** — Organize tasks using Personal, Study, Projects, Other, or your own categories.
- **Task filters** — View all tasks, pending tasks, or completed tasks.
- **Category filtering** — Focus on tasks from a particular category.
- **Progress tracking** — See task totals, completed tasks, remaining tasks, and your overall progress.
- **Local persistence** — Tasks and categories are saved in browser `localStorage`.
- **Light and dark themes** — Switch between the available appearance modes.
- **Responsive interface** — A carefully styled layout designed for comfortable everyday use.

## Data and Privacy

TaskPetal stores task data in the browser's local storage. It does not require an account or send tasks to a project backend. Because data is stored locally, it is tied to the browser and device where it was created; clearing browser data may remove saved tasks.
